A single-line safety warning label that should come printed on every human being — funny first, plausible second. The label is written by `main.py` (Python 3.13, standard library only) to `/output/entry.txt`, 160 characters or fewer.

**The label:** "WARNING: This human has read zero terms and conditions in its lifetime and will still hold you personally responsible for every single one."
